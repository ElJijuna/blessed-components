# Dashboard

Interactive production control-plane template composed entirely from public
component adapters.

```sh
npm run example:dashboard
```

It combines a clickable `MenuBar`, global health, SLO cards, traffic history,
service saturation, deployment state, and a live activity feed. Use Left/Right
and Enter, or click a section, to exercise the navigation contract. Press `q`
to quit.

```sh
npm run example:dashboard -- --smoke
```
