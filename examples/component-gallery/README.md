# Component Gallery

Interactive workbench containing one or more stories for every available
component. The catalog includes a persistent product header, live preview,
story metadata, category context, keyboard navigation, and mouse selection.

```sh
npm run example:gallery
```

Use arrow keys or `j`/`k` and Enter, or click a story to open it. Press `r` to
reload, `Tab` to move focus between the catalog and the active story, and `q`
to quit.

Non-interactive lifecycle check:

```sh
npm run example:gallery -- --smoke
```
